# ADR 0037：口碑巡检只保留单张指标区域证据

- 状态：已接受
- 日期：2026-08-24
- 替代：ADR 0033

## 背景

实际业务查看、XLSX备注和证据包都只需要同时包含车型身份、口碑分、同级排名、口碑量及必要上下文的指标区域。继续保存完整长页会重复占用存储、扩大证据包，并向用户暴露与验收无关的页面区域。真实页面验证已经证明上述信息可以在同一次受控页面访问中形成稳定DOM矩形。

## 决定

映射验证和正式口碑巡检在同一页面上下文中连续三次确认车型身份、指标文字及指标DOM矩形稳定后，直接截取一张不可变 `region.png`。该PNG同时是逻辑页面证据、前端查看文件、单项下载文件、XLSX备注图片和批次证据包成员；记录来源URL、冻结映射、采集时间、页面尺寸、截图矩形、截图尺寸和SHA-256。系统不生成或保存完整长截图，也不为不同用途重复访问平台或生成第二张业务截图。

## 结果

历史数据库兼容字段可以继续指向同一张区域图，但API和界面只提供“指标区域截图”语义。证据完整度按每个需要证据的“车型 × 平台”组合是否具有一张校验通过的区域PNG计算。ADR 0034的两阶段删除继续适用，其文件清单只包含实际存在的区域图及派生产物。
