# ADR 0024：增加本地轻量文字舆情模型选项

- 状态：已接受
- 日期：2026-08-21

## 背景

云端 Omni Plus 能一次处理文字、图片、视频画面和音频，但每帖产生外部 API 用量。部分运行场景只需要标题和正文的轻量舆情分析，因此需要一个无需 API Key、无需媒体处理、可随离线包部署的受控选项。

## 决定

1. 模型下拉保留云端 `qwen3.5-omni-plus-2026-03-15`，新增 `paddlenlp-local-text-nano-v1`。
2. 本地选项固定使用 PaddlePaddle 3.3.1、PaddleNLP 3.0.0b4、UIE-Senta-Nano 与 UTC-Nano，不开放自由模型路径或本地 HTTP 端点。
3. UIE-Senta 使用配置的品牌和重点产品抽取对象、观点与依据；UTC-Nano 先在相关文字上执行负面/非负面分类，只有负面结果再切换到现有六类负面代码。两个模型的原生 JSON 均保存，中文总结由固定模板生成。
4. 本地选项只读取标题和正文。图片、视频画面和视频音频统一记为 `not_requested`，不刷新播放地址、不调用云端 API、不产生计费 Token；详情中的媒体展示保持独立可用。
5. 本地 Taskflow 在进程内缓存，配置测试与 Worker 推理统一投递到一条专用线程串行执行，禁止跨线程复用 Paddle Predictor；云端两个消费者的并发边界不变。
6. 显式模型测试必须同时加载并运行 UIE-Senta 与 UTC。Linux 完整离线包预下载并转换模型，目标机安装和验证过程不访问模型仓库。

## 结果

- 只分析文字时可消除逐帖外部 API 费用，并避免媒体 URL 解析和上传。
- 本地 Nano 不是生成式大模型；中文总结是模板，不具备云端模型同等的别名、隐含指代和复杂语境理解能力。
- 部署包体积、首次组装时间和 CPU/内存需求增加；本地分析吞吐受单进程单推理线程约束。
- 该决定扩展 ADR 0022 和 ADR 0023，不删除云端多模态路径及其配置、安全和失败处理规则。
