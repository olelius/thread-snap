# ADR 0036：手动合成口碑运行与正式巡检完全隔离

- 状态：已接受
- 日期：2026-08-24
- 关系：补充ADR 0032的独立口碑巡检模型，不改变生产环境禁止通用立即巡检的产品边界

口碑比较、页面颜色、XLSX填色、证据分母和汇报异常分支需要在开发与验收阶段快速重复检查。如果只能等待每日10:00并依赖平台实时值，难以稳定制造上涨、下降、方向冲突、无基线、平台暂无和采集异常等场景；如果直接在生产口碑模块增加人工完整巡检，则会破坏一天一个正式批次、冻结前日基线和10:30汇报归属。

因此系统只在显式测试运行模式、启用合成测试能力且使用隔离测试数据库三个条件同时满足时，提供“手动运行测试”。按钮创建带合成来源标识的测试运行，读取后端版本化白名单场景和测试PNG，通过测试采集器输出与正式适配器相同的规范指标及证据合同，随后复用正式比较、证据聚合、结构化汇报快照、TXT、XLSX和页面查询代码。测试运行使用独立身份和查询入口，不访问平台或共享Session，不写正式批次、墓碑、调度事件和基线选择，也不消费日期幂等键；生产环境不注册创建端点，前端环境变量不能单独把按钮打开。

固定场景至少覆盖基线初始化、日常混合变化和月末混合变化。颜色验收只作用于网页指标单元格和XLSX填充，TXT与复制正文保持纯文本。合成结果可以证明处理逻辑和展示分支，但不能替代首个已发布范围在下一个计划10:00形成的真实单平台27项正式运行验收。该隔离增加少量测试适配器和夹具维护成本，换取可重复断言与生产数据语义不受测试便利入口污染。
