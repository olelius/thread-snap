# ADR 0073：负面框只使用与页面证据绑定的卡片几何

风云T9喷粉帖的原始DOM框正确，但像素恢复把扫码浮层的蓝色边缘误认成卡片边界，将框上移94px。换颜色、主题或背景也能触发同类错误；继续调颜色阈值、搜索半径或按页面打补丁都不能建立帖子身份与像素边界的关系。

决定彻底移除基于颜色、纹理和OCR的画框定位。负面结论只通过帖子ID绑定原始清单中的卡片；渲染前校验原始PNG/清单哈希、页面尺寸、帖子ID/URL/顺序、数据库与清单矩形一致、矩形有限正值/页内/不跨相邻卡片，再直接在卡片内绘制红框。未知合同、缺失证据、重复或不一致的几何明确失败，不夹取、不平移、不猜测一个框。

新采集在同一浏览器上下文里取得截图前后的完整几何快照，要求URL、帖子ID/顺序/内容、矩形、文档/视口尺寸、DPR与滚动位置一致，PNG实际尺寸也一致；最多两次同上下文尝试，仍不稳定或截图尺寸不一致时不发布该图，转原任务持久排队并按2秒起、上限60秒退避自动续作；已保存页和帖子复用，不直接判终态失败。不注入CSS或隐藏浮层。新清单记录circle-page-v2-bound-geometry及截图前后摘要。旧circle-page-v1仅按已明确的历史适配器坐标合同解释；汽车之家v10的固定水平边距转换仍可按原合同计算，但任何历史版本都不执行颜色搜索。

原始证据、帖子、AI结论和旧成果不改写。渲染器版本和原图/清单身份纳入输入哈希，修复已有成果只生成后续版本，重复相同输入保持幂等。仅缺证据或坐标依据不足的历史不冒充已修复。本轮只解决框选，不修改此前字体/标题裁剪问题，也不重新访问平台或重判AI。

本决定替代ADR0031、0038及旧链档中的通用像素边界恢复规则；完整原页、同页身份顺序、历史不可变与只画负面框规则保持。

## 截图内部瞬间重排的补充约束

离线长列表复现Chromium full-page内部不再占用经典滚动条时，测量卡片宽870而PNG实际宽879，末行累积偏104px；截图前后读数相同也会漏掉这个瞬间变化。截图专用浏览器从启动即使用原生隐藏滚动条，让document/inner/client宽度一致，不注入网站CSS、不拉长900px初始视口、不移动固定浮层来拼图；新几何证书记录原生策略和实际布局视口。普通认证浏览器不改变。旧懂车帝v4/v7无截图瞬间同宽证明且已观察到漂移，不自动重画，保留现有成果；新证据仅按通用v2证书处理，不再依赖版本号白名单增长。
