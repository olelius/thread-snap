# ADR 0073：直接使用卡片坐标，移除颜色纠偏

风云T9喷粉帖的原始DOM框正确，但像素恢复把扫码浮层蓝色边缘误认成卡片边界，将框上移94px。任何颜色或背景均可能触发，根因是额外猜测边界，而不是AI结论或帖子绑定。

删除颜色、纹理与OCR边界搜索，直接使用既有帖子ID关联的已存矩形，在框内绘制5px红线。保留现有PNG哈希与帖子绑定；旧汽车之家v10只保留确定性的水平margin换算。按用户反馈撤销新增的通用几何证书、重叠/顺序/数据库重复验证模块，不为正确业务数据再建一套校验体系。清单继续使用circle-page-v1，截图策略信息仅作记录，不是渲染准入证书。

另一个已复现的根因是Chromium full-page截图内部移除经典滚动条占位，造成长列表重排：DOM卡片宽870而图上879，末行累积偏104px。截图浏览器从启动使用原生--hide-scrollbars，使测量与PNG同宽；保持1440×900初始视口，不注入CSS或移动浮层。采集只补同宽、截图前后布局及PNG尺寸的必要检查；媒体、来源和帖子身份沿用采集器原逻辑。布局暂态最多同上下文重试一次，再由现有任务按2秒起、60秒上限退避续作，复用已保存页和帖子，不直接终态失败。

原始PNG、清单、帖子、AI和旧成果不覆盖；修复生成后续成果版本。本次仅重生确认原坐标可靠的受影响汽车之家成果。旧懂车帝v4/v7已有累计排版漂移，自动或手动重建遇到已发布版本时保留旧版并明确提示，避免直接按漂移坐标重画；新批次从同宽截图开始。旧成果保留不等于已修复，不伪造历史时点截图。

本决定替代ADR0031、0038及旧链档中的像素边界恢复规则；完整原页、同页身份、历史不可变与只画负面框规则保持。本轮不改字体裁剪，不重新采集平台或调用AI。
