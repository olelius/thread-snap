# 汽车之家帖子点赞数必须由登录会话证明

汽车之家帖子详情的服务端 HTML 固定把点赞图标初始值渲染为 `0`，页面脚本随后调用 `club-open-api.autohome.com.cn/club/zan/list` 更新真实数值；已观察样本的初始值为 `0`、登录后接口值为 `19`。因此 HTML 中的 `0` 是页面加载占位，既不能记作真实零值，也不能静默改为空值。汽车之家帖子适配器必须使用平台官方登录流程建立的独立加密 Session，以 `clubUserShow + autouserid + sessionlogin` 的一致平台 Cookie 组合证明非游客身份，再按页面同款点赞列表接口读取主帖值。缺少 Session、Session 失效或点赞接口拒绝会话时进入既有 `waiting_for_auth` 流程；已证明登录但接口结构、主帖点赞值无效或互相冲突时按字段解析错误失败关闭。

## Consequences

- 汽车之家适配器合同提升为 `autohome-club-v3`，平台注册开启既有认证能力；官方登录、服务器 Profile、加密 Session、有界自动刷新和平台 FIFO 均复用 ADR 0007、ADR 0009 与 ADR 0014，不新增账号密码字段。
- 登录后的点赞接口空列表代表真实 `0`，系统必须保存数字零。HTML占位 `0` 不进入新快照，历史批次中的空点赞数和既有结果保持不可变。
- 认证完成门禁使用已配置的真实论坛来源，至少验证列表首帖详情身份、平台登录Cookie组合及点赞接口均成立；门禁通过后恢复原批次，不创建替代批次。
- 汽车之家正式500条的访问模式固定为认证 Session 后必须从冻结输入开始完整运行，不能与既有匿名预检拼接。
