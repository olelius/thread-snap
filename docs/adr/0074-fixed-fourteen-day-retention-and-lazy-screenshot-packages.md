# ADR 0074：固定14天业务保留与无损截图存储优化

- 状态：已接受
- 日期：2026-09-30
- 授权：用户明确要求“完成截图的处理，以及数据保留相关内容。不需要有配置，默认保留14天”。

## 决定

1. 帖子提取和口碑巡检完整关联链固定保留14天；终态、最后有效业务变更、在途保护和物理文件回收边界由产品设计的“固定14天业务保留”统一定义。每日03:00后及恢复后的同日安全空闲窗口执行，不新增保留配置或页面。
2. 普通批次删除必须整链事务化，并以持久清单保证文件删除失败可恢复；口碑复用既有删除作业/隔离区/墓碑，补齐补跑与汇报安全门，覆盖正式和真实验收历史。配置、会话和仍有效映射不按批次清理。
3. HTTP下载租约覆盖响应实际发送结束/断开；后台操作与保留清理共享单进程生命周期门。维护权未取得时仅延后，不取消在途业务。
4. 无红框成果保留独立路径，优先硬链接原图，不支持时复制；有红框仍独立生成。仅对字节和SHA-256均相同的存量PNG做物理复用，不变更红框像素、原始证据、路径和逻辑归属。
5. 普通圈子ZIP改首次下载时从所选版本冻结manifest/PNG生成；串行去重生成、校验、原子发布，旧ZIP保持原样。历史版本URL不能返回当前版本。新ZIP不重复压缩PNG；没有单独的ZIP保留配置，随业务链14天过期。
6. 本轮不重构帖子正文/评论的大表存储、不引入对象存储或新的配置中心。既有部署当前/回滚/完整离线包保护继续有效。运维备份不属于业务链；保护回滚必需备份与至少一个已校验恢复点，普通备份的固定14天清理在运维权限边界内执行。

## 替代关系与验证

覆盖ADR0026、0031、0038及旧产品/链档中的“永不过期”“零红框必须物理复制”及普通截图预生成ZIP口径，其余原始证据不可变、框线与独立批次语义不变。口碑已有按需ZIP保持其冻结内容规则。

必须验证14天边界、补提链、近期人工修正、活动任务/下载保护、文件失败及重启续清、路径越界、已冻结基线、墓碑、PNG硬链接回退与原图删除后的成果可读、红框逐像素一致、懒包并发及历史包不变；集成环境走真实API/SQLite/磁盘，生产先备份和预览，再核对删除与保留集合。
