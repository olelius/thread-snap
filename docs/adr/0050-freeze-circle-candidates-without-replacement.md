# 圈子任务冻结前 N 个候选且不使用后续帖子补位

圈子截图证明的是来源在一个采集时点返回的具体帖子身份、顺序和卡片。若详情访问失败后继续从列表读取 N+1、N+2 帖子直到凑满 N 条成功结果，最终结果集合就不再等于截图中原本选定的前 N 个候选。隐藏这类补位只能消除异常文案，不能修复证据与结果身份不一致。

圈子任务在详情访问前，按来源冻结顺序确定前 N 个去重帖子身份、规范 URL 和来源位置，N 为任务配置数量；列表不足时冻结实际存在的全部候选。三个平台适配器都只处理这份固定候选清单，任何候选失败都不得触发向列表后方发现替代帖子。

瞬时网络错误不构成候选终态。Worker把原来源 URL 或原候选 URL 连同来源位置写入持久检查点，按2秒起、最高60秒的退避持续重试完全相同的 URL；当前批次保持同平台 FIFO 队首，服务重启后继续，成功后才释放后续批次，同批次其他来源仍可服从内部并发继续。登录失效继续使用既有认证恢复状态机并恢复同一候选。只有平台明确证明帖子删除、身份冲突或内容不成立等非网络结果时，固定候选才进入 `partial_success` 或 `failed`。用户之后执行“重新提取失败项”会创建新批次，并冻结新采集时点的候选与证据，不改写原批次。

## Consequences

- 懂车帝升级为 `dongchedi-dynamic-v6`，汽车之家升级为 `autohome-club-v5`，易车升级为 `yiche-community-v4`；三者采用相同的固定候选和不补位合同。
- 开启页面截图时，结果帖子可以按来源位置追溯到同次页面清单和原始证据；未开启截图的平台仍使用相同固定候选语义。
- 网络中断或平台服务暂时不可达会延长任务并阻塞同平台后续批次，但不会产生用户可见失败项、异常候选或替换帖子；同批次其他来源及其他平台继续按各自容量运行。
- 历史批次、历史截图和已冻结检查点保持不可变。前端对旧成功批次的兼容展示继续存在，但新任务不再生成“失败后补足”的数据形态。
- 本决策替代产品设计、技术路线、链档与ADR 0026中任何“详情失败后向后补足当前任务”的旧口径；ADR 0026关于同一清单、原始证据不可变和关联成果版本化的其余决定继续有效。
