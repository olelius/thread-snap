# 三个平台统一使用可配置的内部总并发

汽车之家和易车最初发布时因正式500条容量验收尚未完成，平台注册上限固定为1。配置页仍允许用户编辑数字，因此输入2后后端把值收敛回1，同时前端显示“保存成功”，形成配置没有生效的直接错觉。当前三平台普通采集均已统一为直连HTTP；汽车之家、懂车帝和易车采集器都使用线程局部HTTP会话，并由采集器实例的共享有界信号量限制全部来源、帖子请求和即时重试的合计并发。

三个已接入平台统一发布1～8的平台内部并发配置范围。保存值属于平台级总容量，不按圈子倍增；Worker创建批次时冻结该值，跨来源任务池和来源内详情池共同服从同一采集器信号量。配置变更只影响之后创建的批次，执行历史快照时仍按当前平台注册上限再次收敛。

## Consequences

- 汽车之家移除采集器内部固定并发1，改为使用平台注册表传入的并发值；易车保留已有的参数化信号量实现。
- 汽车之家和易车的平台注册上限由1调整为8，默认值继续保持1；懂车帝继续默认2、上限8。默认值与可配置上限是两个不同概念。
- 配置接口对1～8原值持久化，对越界值继续按公共合同收敛并返回实际值；前端从能力接口取得相同范围。
- 本决策替代ADR 0044中汽车之家与易车“内部并发上限1”的发布期限制，不改变两个平台正式500条生产验收仍未关闭的事实，也不把本地范围统一表述为特定部署环境已经完成8并发容量验收。
