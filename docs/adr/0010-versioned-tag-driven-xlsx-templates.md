# 使用不可变版本和稳定标签驱动 XLSX 模板

> ADR 0020 已替代本 ADR 的标签格式：第一版正式数据在交付前清理，现只接受 `source.<source_key>.<field>`，不保留本 ADR 的圈子标签兼容分支。

用户可以保存多个命名 XLSX 模板。模板中的数据位置由稳定英文标签 `platform.<platform_code>.circle.<circle_id>.<field>` 指定，而不是由工作表名称、车型中文名或数据库物理字段名推断。同名重新上传创建不可变新版本；导出时选择模板版本。

标签单元格同时是第一条帖子数据单元格。生成器按每个圈子的结果顺序向下写入，一个帖子占一行；同一工作表中的多个圈子列组独立按第 N 条对齐，较短列留空，不建立横向业务关系。用户上传的工作表数量、名称、表头、列顺序和非写入区域均保持原设计。

## 原因

- 车型名称和工作表名称可以修改、重复或包含业务展示文本，不能作为稳定数据键。
- 数据库字段属于实现细节，直接暴露会让模板和存储重构绑定。
- 不可变版本使历史导出可复现；导出时选择模板允许同一批次按不同交付格式生成文件。

## 校验和写入规则

- 上传时校验全部标签、字段、工作表、单元格、合并区域和重复绑定；任一错误拒绝整个模板，并一次返回全部中文定位详情。
- 标签不得位于合并单元格。预计写入范围存在文字、公式或其他内容时终止导出并返回中文冲突位置。
- 后续单元格只克隆标签单元格的字体、填充、边框、对齐和数字格式；第一版不自动填充公式。
- 默认评论集合标签把最多十条主评论按顺序写入一个单元格，每条包含作者、上海时区时间和正文；带点赞标签额外包含点赞数。图片和视频 URL 使用独立集合标签。集合采用编号、中文分号和单元格内换行。
- 单值时间使用 Excel 日期时间值和 `yyyy-mm-dd hh:mm:ss`，缺失值保持空白。
- 导出记录绑定结果汇总版本与模板版本；组合未变化时复用文件，变化时生成新记录。模板删除只隐藏可选项，不破坏历史引用。

## 被放弃的方案

- **按工作表名称或车型名称匹配**：命名不稳定且无法可靠支持同车型多圈子。
- **模板直接写数据库字段名**：泄漏实现细节并阻碍迁移。
- **固定系统工作簿结构**：不能满足用户自定义多个工作表和不同车型布局。
- **一条评论一行**：破坏“一个帖子一行”的交付口径。

本 ADR 固定模板语义和可复现性，不提前确定具体 XLSX 库或对象存储实现。
