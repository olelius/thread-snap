# ADR 0068：口碑未提供指标按空值正常完成

- 状态：已接受
- 日期：2026-09-03
- 关联：`docs/design/product-design.md`、`docs/design/technical-route.md`、`docs/chains/reputation-inspection.md`
- supersedes：`ADR 0039`（未开售空态的严格三来源门禁部分）、`ADR 0064` 第3、7条关于缺失指标与差评率的异常状态部分

## 背景

真实巡检中，平台可能只返回部分指标。未上市车型或平台未展示排名时，`score`、`rank`、口碑量、评价篇数或差评率可能为空；这不等同于页面访问失败，也不应把已经取得的其他指标标成异常。此前把页面存在但字段缺失统一记为 `unknown` 并提升为部分成功，导致正常的空字段显示为“异常”。

## 决定

1. 三个平台对五个指标分别读取，平台没有返回的单项统一保存为 `not_available` 的空值；不使用历史值、零值或推测值补齐。
2. 缺少 `score`、`rank` 或差评率标签不改变执行项状态，不计入批次异常，不触发失败项补跑；其余指标、页面证据和比较结果照常保存。
3. 懂车帝差评率接口缺少优缺点标签时，差评率留空并继续保存页面结果；只有接口/页面访问、身份、结构无法识别或证据门禁失败才形成异常。
4. 汽车之家和易车的页面测量允许评分、排名、参与人数或评价总数节点缺失，只要车型身份和可截图区域成立就继续保存结果与证据。
5. 前端排名表、汇报与 XLSX 对空指标只显示空白（`—`），不附加“异常”或单独状态文字。真正的访问、身份、结构和证据失败继续沿用现有异常与补跑流程。

## 影响

- 批次进度中的“已处理”仍表示所有车型平台项到达终态；空指标不再把成功项转换为部分成功。
- 页面证据完整度独立于指标完整度；只要页面证据成功保存，空指标车型仍计入完整证据。
- 差评率来源后续若得到可靠分子和分母，只影响该指标的采集值，不改变其他指标的空值语义。
