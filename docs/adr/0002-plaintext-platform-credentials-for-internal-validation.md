# 内部验证版明文持久化平台密码

ThreadSnap 优先使用未登录方式采集。真实样本证明必须登录时，内部验证版允许用户通过配置页面录入平台账号和密码，并由提取功能服务在本地数据库中明文保存密码。

该决定用于降低第一版开发复杂度，避免在受控内部验证阶段建设应用层加密、独立密钥管理和完整凭证权限系统。项目明确接受数据库文件泄露时平台密码可能直接暴露的风险。

## Consequences

- 密码通过配置页面写入本地数据库。
- 内部验证版只保存一套全局懂车帝账号，所有提取配置共用，不支持多账号选择或轮换。
- 查询接口不得返回密码，只返回是否已经配置。
- 修改密码时覆盖原值，不提供读取、复制或恢复原密码功能。
- 密码、Cookie 和会话状态不得进入列表、日志、错误信息、导出文件、测试报告或 Git。
- 未登录模式满足需求时不保存平台账号密码。
- 本决定只适用于不部署公网的内部验证版。
- 正式公网版本集成前必须将密码和会话秘密迁移为加密持久化，并建立独立密钥管理和凭证访问权限。
- 正式版升级时必须验证所有遗留明文凭证已经加密迁移或安全清除。
- 未完成加密迁移时，不得把内部验证版直接作为公网正式版本部署。
