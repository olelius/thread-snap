# ADR 0032：将垂媒口碑巡检与帖子提取分成独立业务模块

- 状态：已接受
- 日期：2026-08-24

## 背景

垂媒口碑巡检以“日期 × 车型 × 平台”的口碑分、排名和口碑量为核心结果，并依赖跨期比较、日检/月检证据范围和定时汇报；现有帖子提取则以圈子或 URL 清单发现的帖子快照为核心结果，页面截图只是同一冻结帖子清单的证据视图。两者的结果粒度、历史关系、调度语义和验收分母不同。

## 决定

垂媒口碑巡检使用独立的“口碑巡检批次”领域对象和一级前端业务入口，不作为现有提取批次详情中的第三种结果。口碑巡检批次详情内部使用“排名数据”“页面证据”“汇报结果”三个同级视图。它继续复用 ThreadSnap 的应用外壳、前端技术栈、调度与状态基础设施以及可复用展示组件，但不复用提取批次作为其领域模型，也不增加第二套前端或业务后端。

## 结果

现有“链接结果 / 页面截图”的帖子批次语义保持不变；口碑巡检可以独立演进其车型矩阵、比较基线、日检/月检和汇报规则，前端无需在同一详情组件中按批次类型维护两套互斥字段与筛选逻辑。
