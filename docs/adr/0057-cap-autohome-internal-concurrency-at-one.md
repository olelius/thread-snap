# 汽车之家平台内部总并发固定为一

## Context

ADR 0049 曾把三个帖子采集平台统一开放为1～8的可配置内部总并发。汽车之家随后在
`autohome-club-v9-scrapling-auth-gate`上完成同条件真实对照：内部并发2的420条批次在
218条时进入`PLATFORM_CHALLENGE`，更新Session后原位完成；内部并发1的独立420条批次
用148.272秒完成420/420，独立1000条来源结果批次用860.500秒完成1000/1000，两个
单并发批次均为最终失败0且没有验证码、挑战或限流。1000条轮次中的20次TCP连接超时
均由原URL持久重试恢复，DNS诊断同时证明本机仍经过`198.18.0.x`合成地址转发层，因此
该网络异常不作为提高平台并发的理由。

单并发两轮成功只证明已记录Session、网络和时间窗口下的稳定性，不代表长期免验证；但
继续向用户暴露汽车之家2～8会允许未来批次重新放大已观察到的控制风险，且当前业务没有
必须以更高并发换取的验收目标。

## Decision

- 汽车之家平台注册范围固定为`min=1, max=1`，配置接口把任意更高输入收敛为1。
- `AutohomeCollector`自身再次把构造参数收敛为1，覆盖注册表、Worker和验收入口之外的
  直接构造路径。
- bootstrap把旧数据库中汽车之家高于1的当前配置收敛为1；新批次只冻结1。
- 已完成历史批次及其创建时快照保持不变；认证恢复探针仍使用1，释放其他来源后平台总
  并发也继续为1。
- 懂车帝和易车继续保留1～8范围；口碑巡检固定并发2的独立合同保持不变。

本决策只替代ADR 0049中汽车之家的1～8可配置范围，不改变该ADR对懂车帝、易车和平台
共享总信号量语义的决定。

## Consequences

- 前端汽车之家并发输入范围显示为1～1，保存更高值时后端权威返回1。
- 汽车之家跨来源任务仍可同时处于运行状态，但所有列表、详情、点赞、评论和即时重试通过
  同一信号量逐个发出平台请求。
- 吞吐下降属于接受的代价；瞬时网络错误继续在原URL持久重试，不转成平台控制或终态失败。
- 后续若有新的生产环境容量证据需要提高上限，应以新的ADR和独立固定输入轮次重新决定，
  不直接修改数据库值。
