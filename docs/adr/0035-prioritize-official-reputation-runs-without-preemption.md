# ADR 0035：每日正式口碑巡检使用非抢占优先级

- 状态：已接受
- 日期：2026-08-24
- 关系：为ADR 0009的平台严格FIFO增加窄范围例外，不替代其余队列语义

每日正式口碑巡检需要在10:00后尽快形成当天指标与汇报输入。如果完全排在已入队的大型帖子批次之后，口碑结果耗时将由无关任务队列长度决定；如果抢占正在运行的帖子请求，则会破坏帖子检查点、截图上下文和平台访问稳定性。因此平台容量调度采用非抢占优先：已经开始并持有容量槽位的帖子请求继续完成，槽位释放后优先分配给已经到达的普通日检、月末巡检或同日延迟正式口碑批次；尚未开始的普通任务暂缓领取，正式口碑终态后仍按原FIFO相对顺序恢复。

该优先级不授予口碑失败项补跑、映射验证、手动任务或帖子补提，也不跨平台阻塞。所有任务继续共享同一平台内部总并发，优先级只改变下一个空闲槽位的领取顺序，不改变已运行工作、历史快照或重试预算。该方案以最小例外保护固定汇报时效，同时避免建立可配置优先级系统或任意插队入口。
