# ADR 0064：以平台注册表接入汽车之家与易车口碑巡检

- 状态：已接受
- 日期：2026-09-03
- 关联：`docs/chains/reputation-inspection.md`、`docs/chains/later-platform-delivery.md`、`docs/design/product-design.md`、`docs/design/technical-route.md`

## 背景

口碑巡检原实现把懂车帝代码、URL规范、适配器版本、映射哈希、正式运行目标和导出列写成单平台路径。汽车之家与易车已经具备共享Session和浏览器运行基础，但平台页面的稳定身份、排名范围、评价篇数与差评率语义不同，不能通过复制懂车帝选择器或把相似名称自动绑定为同一车型来接入。

2026-09-03 的真实代表样本确认：

- 汽车之家使用 `https://k.autohome.com.cn/<series_id>/`，页面与同次官方接口可取得车系身份、口碑分、带范围的排名、参与人数和全部口碑文章数；当前页面的正负标签提及占比不是平台官方差评率。
- 易车使用 `https://dianping.yiche.com/<slug>/koubei/`，页面与同次签名接口可取得车系ID、车型身份、口碑分、带范围的排名、参与人数和点评总数；满意或不满意标签当前没有形成可复算的差评率分子、分母。
- 两个平台都能在一次浏览器访问中连续三次稳定测量并保存唯一指标区域PNG，但页面可见排名范围和接口排名范围必须分别保留名称，不能只保存名次数值后跨范围比较。

## 决定

1. 新增口碑平台注册表。每个平台注册稳定代码、展示名、URL规范函数、适配器工厂、适配器版本、验证合同版本和视口；公共服务不再直接依赖懂车帝私有类型。
2. 汽车之家和易车复用懂车帝已经确认的业务流程：单平台草稿编辑、真实身份/指标/证据门禁、显式发布、固定并发2的正式日检/月末/补跑、逐项持久化、不可变截图、前日比较、平台分组汇报、证据包和固定XLSX。
3. “流程一致”不表示平台原始字段或数值语义相同。平台适配器必须保存实际排名范围和来源；范围改变时排名不可比较。已有页面但缺少可靠指标来源时保存 `unknown`，执行项和批次保持部分成功；只有页面明确证明没有口碑数据时才保存 `not_available`。
4. 范围发布按当前草稿中实际出现的平台计算完整笛卡尔积。某平台只要进入当前草稿，就必须为全部启用车型保存并验证映射；发布后批次冻结实际平台顺序和 `车型数 × 平台数` 分母。旧懂车帝范围与历史批次保持27项，不被自动扩张。
5. 正式运行的90秒单项上限、一次暂时错误重试和45分钟整批硬上限由三平台共享；三个平台注册通道同时进入执行；页面打开、稳定测量、截图和即时重试通过共享全局信号量最多占用两个槽位，任何时刻全局也不超过固定并发2。
6. 排名页继续一款车型一行，每个平台显示五指标与状态/证据六列组。XLSX按平台生成五指标列，但每款车型只保留一个备注单元格；多平台截图按冻结顺序生成带平台名的单张派生预览，保存来源证据ID、来源哈希与预览哈希，原始平台PNG不变。
7. 当前汽车之家与易车差评率没有可靠平台来源，保留 `unknown`，不以标签提及占比或空标签计数伪造数值。候选映射仍需逐项人工确认并通过真实页面门禁；候选生成本身不触发发布或生产数据库变更。

## 影响

- 后端、前端、汇报和XLSX可以处理懂车帝、汽车之家与易车的任意已发布平台组合，完整三平台范围的目标分母为81。
- 平台新增或合同变化只修改注册项和对应适配器，不再复制调度、范围、证据、汇报与导出服务。
- 汽车之家或易车在差评率仍为 `unknown` 时会留下真实截图和其他可靠指标，同时显式形成部分成功，失败项补跑不会用旧值补齐。
- 代表样本证明代码路径和截图合同成立，但不替代27款逐项映射确认、全量真实运行或正式范围发布。

## 未采用方案

- 复制两份懂车帝服务：会产生三套调度、证据和历史规则，公共行为容易漂移。
- 按名称相似度自动发布27款映射：无法区分动力版本、聚合车系和换代车型，错绑后会污染前日序列。
- 用汽车之家优缺点标签提及占比或易车空标签过滤结果充当差评率：两者都没有与业务差评率一致的可靠分母。
- 为完成五列而把缺失值写成零：零是业务数值，`unknown`才表达当前证据边界。
