# 分离本地适配器发布与正式样本验收

## Context

ADR 0043定义了汽车之家与易车各自500条冻结样本的真实验收合同。汽车之家随后已经完成统一采集器实现、真实字段与媒体合同、本地Worker/API/XLSX闭环和自动化测试，但平台注册仍保持 `not_integrated`，导致本地配置页继续显示“未接入”，本地开发成果也无法通过正常启用入口运行。

用户明确要求完成本地开发接入。`adapter_status` 同时承担“代码是否已发布”和“正式环境大样本是否已验收”会混淆两个阶段。

## Decision

1. `adapter_status=available` 表示适配器代码、平台注册、公共业务路径和本地自动化闭环已经发布，可由用户显式启用；新发布平台仍默认停用，不自动扩张既有规则或来源。
2. 正式500条冻结样本继续作为正式环境接入验收、可持续访问和规模运行声明的门禁，不再阻塞已经完成本地闭环的平台显示为“已接入”。
3. 汽车之家以 `autohome-club-v1` 发布为 `available`，默认停用、内部并发上限1；页面证据和正式认证能力继续按当前真实能力关闭。
4. bootstrap以collector registry为适配器发布状态的唯一来源：registry发布时提升既有数据库状态，但保留用户的启用选择；registry撤回时关闭平台并收口活动任务。
5. 易车不随本决策自动发布，继续按其当前证据和独立任务决定 `adapter_status`。

## Scope and compatibility

- 本决策调整ADR 0043中“500条验收直接控制本地 `available` 状态”的解释，不改变500条输入、唯一终态、字段合同、证据保存和失败后完整重跑要求。
- 汽车之家未完成的正式500条、可持续访问模式、页面证据和口碑指标仍按原owner文档保留为明确缺口。
- 平台可用与平台启用仍是两个字段；本次发布不会自动创建来源、修改规则或创建任务。

## Consequences

- 本地配置页能准确显示汽车之家适配器已经接入，并允许用户主动启用。
- 页面不得把“已接入”解释成正式500条或生产环境验收完成；对外验收结论必须继续引用真实证据。
- registry发布状态变化必须有bootstrap升级测试，避免数据库保留旧状态导致界面继续显示“未接入”。
