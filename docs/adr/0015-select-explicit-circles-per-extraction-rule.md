# 自动提取规则明确选择平台圈子

自动提取规则保存明确的平台圈子 ID 集合，并只为这些圈子涉及的平台保存统一每圈有效结果目标数。前端按平台和车型分组展示圈子，平台复选框只是批量选择交互；保存时必须展开为当时的明确圈子 ID，因此后续新增平台或圈子默认不进入既有规则。规则名称、圈子范围或平台数量变化均生成同一逻辑规则的新版本，已经创建的批次继续保留原版本与来源快照。

平台配置继续独占接入、启用、并发和 Session；车型与圈子继续独占来源资料、验证状态和全局自动提取资格；规则只拥有该规则的来源成员关系和定时数量。实际触发范围为“规则所选圈子 ∩ 已接入且启用平台 ∩ 已验证且全局启用圈子”。这两层开关分别表达全局运行资格与规则成员关系，不是同一字段的重复编辑。

后续平台接入后保持停用，既有规则也保持未选择；启用平台不要求所有规则自动补齐该平台数量，也不扩张任何规则。规则选择该平台任一圈子时必须同时保存平台数量，取消最后一个圈子时移除数量。规则选择为空时可以作为未完成草稿保存，但启用的计划节点不得引用空范围规则。平台未接入时其圈子不能进入规则。

圈子仍被任一未归档规则当前版本选择时阻止删除；用户需要先保存移除该圈子的规则新版本。调度触发只为当前仍可执行的已选圈子创建任务，全部不可执行时不创建空批次而记录中文事件；若异常数据导致已选且可执行的平台缺少数量，则整次节点触发停止，不静默创建部分批次。

本决策替代 ADR 0013 中“规则不选择平台、车型或圈子”“规则作用于全部合格来源”以及“平台启用要求全部启用节点规则覆盖该平台数量”的部分；ADR 0013 关于节点只引用规则、配置唯一归属、规则不可变版本和计划时间全局唯一的其余决策继续有效。
