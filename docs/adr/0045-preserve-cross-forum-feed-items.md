# 保留圈子列表中的跨论坛聚合帖

汽车之家真实“风云A9论坛”列表会稳定返回由其他车型论坛原发、但被平台聚合到当前列表的相关帖子：列表上下文字段指向当前来源，APP跳转和详情身份指向原始论坛。ThreadSnap的圈子发现职责是冻结所选来源实际返回的有序帖子链接，而不是把平台列表重新解释为原始论坛成员查询；因此只要列表来自任务冻结来源，列表帖子ID、详情URL和详情帖子ID一致，且列表APP跳转声明的原始论坛与详情身份一致，跨论坛聚合帖就计入有效结果。批次继续保存任务的发现来源，并在帖子原始状态中分别保存详情原始论坛及跨论坛标记；只有帖子ID不一致、列表响应不属于请求来源，或列表声明的原始归属与详情再次冲突时才按错帖失败。该决策避免把平台实际前N条改写为过滤后向后补足的另一组结果，同时不把原始论坛伪装成发现来源。

## Consequences

- 汽车之家适配器合同提升为 `autohome-club-v2`；既有批次保持不可变，不回写历史结果或失败计数。
- 列表和详情同时展示任务发现来源；跨论坛帖子额外标记原始论坛ID，导出和去重仍以平台帖子ID及任务来源快照为准。
- 正式500条验收中的“错帖”不包含已证明的跨论坛聚合帖；帖子ID冲突、来源响应越界和原始归属再次冲突仍失败关闭。
