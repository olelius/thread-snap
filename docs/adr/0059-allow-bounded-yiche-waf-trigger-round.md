# 易车 WAF 逆向允许有界主动触发轮次

## Context

ADR 0058 已经把易车登录失效、详情挑战、腾讯验证码和 HTTP 429 分开处理，固定
1000 个不同详情 URL、实际并发 1 的诊断批次也证明：并发 1 只实现串行，没有显式
限速；两个无并行探针干扰的恢复周期都在新增约 57 条后再次出现腾讯验证码。原逆向
流程只允许等待自然挑战，虽然请求最少，但会让工具链验证完成后的动态分析无限等待。

用户于 2026-09-01 明确允许为了完成本次逆向调研制造高频请求。该授权只改变隔离
调研的取样方式，不改变生产采集器、平台并发范围、普通批次恢复、正式 500 条门禁或
对平台固定阈值的判断。

## Decision

- 在 DevTools MCP、隔离浏览器、回环 CDP、Git 外目录和本地静态页门禁全部通过后，
  允许执行一次易车详情路由主动触发轮次。
- 触发输入由既有已验证来源重新现时冻结为最多 80 个不同详情 URL；不得复用已完成
  1000 条轮次冒充新样本，不得重复敲击同一 URL。
- 轮次固定同一出口、账号 Session、Profile 副本和 HTTP 传输，实际并发固定为 1，
  不插入人为请求间隔。80 是本轮请求硬上限，不是平台阈值。
- 使用隔离触发驱动器按清单顺序访问，并在 Git 外 `manifest.json` 中逐项记录位置、
  时间、响应类别和脱敏哈希；它不创建正式批次，也不修改生产 Session 或数据库。
- 首次观察到 `PLATFORM_CHALLENGE`、`PLATFORM_CAPTCHA_REQUIRED` 或
  `PLATFORM_RATE_LIMITED` 时立即终止新增详情请求。挑战或验证码进入原触发 URL
  取证；429 只形成限流样本并结束该轮，不自动扩大清单或等待后继续请求。
- 80 个 URL 全部返回正文而未出现控制时，该轮结论为“未触发”，不得自动提高并发、
  增加上限或循环运行；需要新一轮时重新形成明确决策和独立轮次目录。
- 主动触发取得的样本与自然挑战使用相同的 frame、脚本、网络、调用栈、Cookie 名称
  变化、正文门禁、脱敏、停止、回滚和版本失效合同。

## Consequences

- 工具链门关闭后不再无限等待自然挑战，可以用一个有界轮次取得动态分析样本。
- 本轮最多新增 80 个不同详情请求，且首个控制即止损；不会重复历史 1000 条诊断，
  也不会把触发轮次计入正式 500 条验收。
- 80 条内未触发、先出现 429、挑战自然消退或脚本版本变化都可能使本轮无法关闭完整
  逆向链；这些结果必须按实际证据记录，不能通过自动加压改写。
- ADR 0058 继续管理生产分类与恢复；任何生产自动化仍需新的设计、ADR、测试、目标
  场景验收和回滚。

## Outcome

- 历史`js-reverse-mcp@1.2.1`静态核心门通过后执行了两个独立取样轮次；第1轮浏览器没有继承HTTP传输风险状态，未保留原始WAF，因而以新的零重叠80 URL输入形成第2轮明确决策和独立目录。
- 两轮均在前59个正文成功后由第60个请求命中`PLATFORM_CAPTCHA_REQUIRED`并立即止损；每轮剩余20个URL未请求，没有提高并发、扩张上限或循环施压。该重复位置不是固定平台阈值。
- 第2轮在Fetcher内部冻结了等字节WAF响应，随后完成SDK/iframe/TDC、双图、本地识别、腾讯verify和WAF客户端回调链。原风险会话到易车详情正文门禁未关闭，生产决策为只保留研究产物，ADR 0058保持不变。
