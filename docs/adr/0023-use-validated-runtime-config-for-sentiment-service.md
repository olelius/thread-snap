# 舆情模型服务采用可验证的受控运行时配置

舆情接入需要让部署后的单一内部使用者替换 API Key、切换官方或代理端点并启停分析；继续只用环境变量会迫使每次变更都登录服务器，而接受任意端点又会引入密钥泄露和服务端请求伪造风险。ThreadSnap 因此在“AI 舆情”配置中持久化受控运行时配置：API Key 以既有 Fernet 密钥加密且只写不读，模型来自经过验证的下拉目录，Base URL 只接受通过地址与重定向安全检查的公网 HTTPS OpenAI 兼容端点，任何关键字段变化都会使连接验证失效。

保存配置本身不调用模型；只有显式的最小文字连接测试成功后才能开启分析。第一版目录只包含 `qwen3.5-omni-plus-2026-03-15`，不支持自由模型名、本地 HTTP 模型地址、代理商自定义余额接口或阿里云财务凭证。关闭分析不取消已经发出的付费请求，排队任务与关闭期间新帖进入不可自动恢复的禁用状态；认证或配置错误使用可恢复的暂停状态。

该决策保留 ADR 0022 的在线多模态 API、URL 直传和应用内持久 Worker，不把兼容代理扩张为通用模型平台。它只替代 ADR 0022 中“API Key 不进入前端”的绝对表述：密钥可以通过同源 HTTPS 或全回环连接一次性写入，但永不由服务端返回，也不持久化到浏览器；远程纯 HTTP 入口不得接收凭证。代价是服务端需要承担加密配置、连接验证和 SSRF 防护，并明确告知使用者第三方代理可以接收密钥、正文和媒体 URL。
