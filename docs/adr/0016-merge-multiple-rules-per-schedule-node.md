# 每周计划节点多选规则并合并为一个批次

每周计划节点可以引用一条或多条已经保存的自动提取规则。同一实际触发点只创建一个顶层定时批次：调度器在事务中冻结全部规则的逻辑 ID、当前版本、名称、圈子范围和平台数量，逐规则解析当前可执行圈子后按圈子 ID 求并集。相同圈子被多条规则选中时只创建一个圈子任务，其有效结果目标数采用这些规则中的最大值，不相加，也不重复访问；批次与圈子任务快照同时保留全部来源规则，保证历史解释和后续排查不依赖当前配置。

节点仍按逐日展开后的“星期 + `HH:mm:ss`”全局唯一，定时幂等键仍使用“节点 + 计划触发时刻”，因此多选规则不会改变一次触发最多一个批次的约束。任一所选规则不存在、被归档或出现可执行平台数量缺失时阻止整次触发；全部规则均没有可执行圈子时记录跳过事件而不创建空批次。规则仍被任一节点引用时不得归档或删除，形成任一批次规则快照后只能归档。

持久化以节点规则关联表和批次规则版本关联表为权威来源；旧单规则列仅作为已交付前数据库的兼容指针，读取、校验、调度和历史使用判断均不依赖该列。页面与集成 API 的节点写模型使用非空 `rule_ids`；前端只把计划卡片原规则选择器替换为可搜索多选器，其他布局和编辑职责不变。

本决策替代 ADR 0013 中“一个节点只引用一条规则”以及由此推导出的单规则批次快照部分；ADR 0013 关于计划与规则职责分离、配置唯一归属、规则不可变版本和计划时间全局唯一的其余决策继续有效。ADR 0015 的明确圈子范围继续有效，并作为多规则合并的输入。
