# 主评论作为帖子附属快照而非整帖有效性门禁

汽车之家真实批次 `20260830-120826-001` 中，32个身份、正文和点赞均有效的帖子仅因详情页没有输出评论分页终止标记而被向后补量。现场复核显示其中30条的列表回复数与详情一级评论数完全一致，另外2条也具有有效帖子身份和正文。懂车帝现有实现同样会保存已经取得的评论并正常返回帖子，不以评论数量或分页终止证明淘汰整帖。

主评论是帖子快照的附属内容。帖子身份成立且正文或媒体有效时，汽车之家和易车均正常保存帖子，并按平台当前响应顺序最多保存10条已经取得的一级评论。评论为空、数量与列表值不同、分页仍有后续、终止标记缺失或评论响应结构不可用时，不增加批次失败数，不向列表后方补量，也不在结果页显示异常或待确认状态。评论身份不一致时丢弃该次评论响应，仍保留帖子；登录失效、验证码、限流等平台控制继续进入既有控制状态机。

## Consequences

- 汽车之家适配器升级为 `autohome-club-v4`，移除 `POST_COMMENTS_INCOMPLETE` 整帖失败门禁；详情SSR实际返回多少条一级评论就保存多少条，最多10条。
- 易车适配器升级为 `yiche-community-v3`，评论首批响应只负责提供最多10条附属内容，不再以分页终止、响应缺失或结构差异淘汰帖子。
- 正式500条验收继续检查帖子身份、正文或媒体、评论上限和评论归属，不再要求每条帖子证明评论分页完整结束。
- 历史批次及其失败计数保持不可变；新批次按新适配器合同生成正常帖子结果。
