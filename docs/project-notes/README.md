# 历史项目记录

根目录 `WORKLOG.md` 是唯一活动任务账本，也是上下文压缩、新会话和任务恢复的唯一进度入口。本目录不得再建立 `current-progress.md` 或其他平行活动账本。

本目录只在确有审计或交付价值时保存已经结束且冻结的阶段记录。历史记录：

- 不声明当前状态、下一步或活动阻塞项；
- 不复制 `WORKLOG.md`、产品设计、技术路线或 ADR 的当前口径；
- 不作为新任务的默认读取材料；
- 不包含敏感信息、Cookie、令牌、平台响应原文或大体积日志。

详细临时证据统一放入被 Git 忽略的 `artifacts/runtime/`；长期有效结论应提升到对应 owner 文档、ADR 或一事一文件的项目记忆。

完整文档地图和读取顺序见 `docs/README.md`。
