# WORKLOG 条目模板

本文件只是写入根目录 `WORKLOG.md` 的条目模板，不是第二份账本。新条目放在“待你裁决”小节后的最上方。

```markdown
## YYYY-MM-DD — <一句话交付物>

**总目标**：<做成什么样算完成，不写过程>

**状态**：🚧 进行中 / ✅ 完成 / ⏸️ 阻塞

**干到哪了**：

- [x] <已完成步骤>；证据：<命令、关键输出、产物路径或身份>
- [ ] <下一步：具体到文件、动作和验证入口>

**下一步**：<恢复后直接执行的唯一下一动作>

**边界**：<明确不做什么、不碰哪些文件或哪些结论仍待验证>

**关联**：<分支、issue、PR、链档或 ADR>
```

条目必须让零上下文 Agent 只读这一条就能继续；需要翻完整聊天记录才能理解的条目不合格。
