# 链档模板

本文件用于创建 `docs/chains/<workstream>.md`，本身不承载任何工作线口径。

```markdown
# 链档：<工作线名称>

## 当前口径

- <此刻生效的结论、边界和约束；被新决定覆盖时就地改写>
- <指出功能、技术或 PoC 细节的唯一 owner 文档>

## 决策链

| 日期 | 决定 | 为什么 |
|---|---|---|
| YYYY-MM-DD | <每个任务只写一行决定> | <一行理由> |

## 未决项

- [ ] <问题> —— 解锁条件：<谁提供什么，或什么证据出现后可解决>
```

细节证据属于 `WORKLOG.md` 的证据入口或 `artifacts/runtime/`，不复制进链档。
