# 在线多模态舆情反馈 PoC 结果

## 1. 结论

- 状态：主 PoC 已按“30 条真实视频 URL 传输验证 + 1 次千问视频端到端调用 + 0 次自动重试”的受控范围执行完成；2026-08-20 另以独立单次调用补充了真实图文用量样本，不改变主 PoC 的冻结分母。
- 媒体路径：30/30 条视频均从圈子帖子取得 `vid`，详情接口的 `video_play_info` 均为空；使用已有加密平台 Session 启动完整 Chromium，在请求层阻断媒体正文后读取播放器 `currentSrc`，30/30 取得直接播放 URL。
- 公共可达性：30/30 条 URL 在无 Cookie、无 Referer 的 `HEAD` 请求中返回 HTTP 200 和 `video/mp4`。本轮未在后端下载、转码、抽帧或语音转写视频。
- 模型路径：唯一一次 `qwen3.5-omni-plus-2026-03-15` HTTP 请求返回 200，提供方用量同时包含视频和音频 Token；模型声明视频画面已处理、视频音频为有语音。
- 结构路径：模型在 JSON 对象后额外输出了 Markdown 结束围栏，原始响应不满足严格 JSON；本地只移除该围栏后通过既定结构校验。后续实现必须保留原始响应，并把“原始结构有效”和“本地确定性恢复有效”分开记录。
- 路线判断：当前证据支持继续采用 URL 直传，不引入视频下载、中转、对象存储或转码。一次模型样本只证明链路可行，不代表其他 URL、静音视频、模态冲突或长期签名 URL 的模型成功分布。

## 7. 后续实现门槛

PoC 已足以支持进入最小功能实现，并保留以下约束：

1. 视频 URL 解析必须作为 `video_play_info` 为空且 `vid` 存在时的有界回退；媒体请求在解析阶段保持阻断。
2. 正式模型客户端使用 `stream=true`，但业务层仍以一帖一份聚合结果落库。
3. 使用 JSON Object 模式并执行本地 Schema 校验；原始严格 JSON 失败时，只允许可审计的确定性围栏清理，其他格式错误形成部分或失败结果。
4. 当前模型调用证据分母为 1。正式实现不得把它写成 30/30 模型成功率，也不预设静音、失效签名和模态冲突样本的表现。
5. URL 直传失败时记录事实，不自动启用下载回退。
