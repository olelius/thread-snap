## 已确认边界

- 该能力是每帖一次的在线多模态模型调用，不是本地小模型或对话型智能体。
- 第一轮固定使用 `qwen3.5-omni-plus-2026-03-15`，不使用第二模型、RAG、工具或联网搜索。
- 输入只有帖子完整标题、正文、全部图片 URL 和全部视频 URL；评论不参与。
- 视频必须分别处理画面和音频。ThreadSnap 优先直传 URL，不下载、中转、转码、抽帧或 ASR。
- AI 原始响应和规范化结果同时保留；程序只校验结构与覆盖，不判定模型是否“答对”。
- 完整 AI 反馈可以成为默认有效结论；人工修正优先且追加保存。人工复核随机发生，不设置强制比例或多人一致性流程。
- 同帖内容未实质变化时继承人工判定；无人工结果时只精确复用版本和输入完全一致的完整 AI 结果。任何历史批次保持不可变。
- PoC 是 URL 获取、模态覆盖、结构、耗时、用量、成本和失败分布报告，不设置准确率、召回率、误判率或漏判上限。

## 决策链

| 日期 | 决定 | 为什么 |
|---|---|---|
| 2026-08-19 | 不采用本地语义小模型或对话型 Agent，改用每帖一次的在线多模态 API | 需求是确定输入到结构化结果的单次处理，没有对话、规划、检索或工具使用；本地方案的视频画面与音频能力也未获证据 |
| 2026-08-19 | 第一轮固定百炼 `qwen3.5-omni-plus-2026-03-15` | 固定快照便于复现；官方接口允许文字、图片、音频和视频组合输入，真实 URL 能力仍须 PoC |
| 2026-08-19 | 优先让提供方直接读取完整媒体 URL | 避免 ThreadSnap 承担视频下载、磁盘、带宽和转码成本；防盗链与签名失败按真实样本分布再决策 |
| 2026-08-19 | 提取提交后创建同进程持久分析任务 | 隔离提取和外部模型延迟，同时复用现有单进程与 SQLite 部署，不提前引入消息中间件或微服务 |
| 2026-08-19 | 只保存和展示真实模型反馈，不建设准确率裁决门禁 | 当前目标是忠实保留单一模型返回，不存在要求每条复核的金标准流程；程序只验证结构和模态覆盖 |
| 2026-08-19 | 人工随机复核且结果优先，内容未变化时向未来快照继承 | 满足实际偶发纠正需求，避免重复修正同一内容，同时保持历史批次不可变 |
| 2026-08-19 | 当前无视频数据，先补至少 30 条真实视频样本 | 本地 842 个不同帖子中视频样本为 0，现有数据不能回答视频 URL、防盗链、画面和音频覆盖问题 |
